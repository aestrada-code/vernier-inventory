# Vernier Inventory

Visual equipment inventory for an IB ESS laboratory.

## GitHub Pages
Push this repository to GitHub using the `main` branch. The included GitHub Actions workflow deploys the static site to GitHub Pages.

## Images
Equipment records are stored in `equipment.json`. The `image` field can contain a local path such as `images/light-sensor.jpg` or an image URL. For long-term stability, local copies of official product images are recommended.
